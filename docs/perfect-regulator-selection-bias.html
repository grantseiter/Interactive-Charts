The Perfect Regulator

For each site we imagine a local infant-health index under two states of the world: Y1 if it is cleaned and Y0 if it is not. The individual effect is δ = Y1 − Y0. We only ever observe Y = D·Y1 + (1−D)·Y0 (the switching equation). Both potential outcomes are visible here only because this is a simulation — in real data one column is always missing.

Decomposition of the SDO
SDO · = ATE · + selection bias · + heterogeneity bias ·
selection bias = E[Y0|D=1] − E[Y0|D=0]  ·   heterogeneity bias = (1−π)(ATT − ATU)
·

Things to try

  • Start with the Perfect Regulator. Note that cleanup helps on average (ATE > 0) yet the SDO is negative: targeting the neediest sites makes cleanup look harmful.
  • Switch to Random. Selection bias and heterogeneity bias collapse toward zero and SDO → ATE. That is what randomization buys you.
  • Switch to Bad Regulator. Now the bias flips sign.
  • Edit the Y0 column so the cleaned sites start out much worse off and watch selection bias grow.
